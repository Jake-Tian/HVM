# Hierarchical Video Memory

Pipeline for building graph memory from web videos and answering QA with graph, OCR, and video reasoning.

## Quick Start

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```
2. **Set API credentials**
   - Ensure the required OpenAI and Hugging Face credentials are available in your environment.
   - Text and multimodal model calls are centralized in `utils/llm_gpt.py` and `utils/mllm_gpt.py`. Qwen adapters are available in `utils/llm_qwen.py` and `utils/mllm_qwen.py`.
   - Embedding calls are centralized in `utils/embedding.py` and use `text-embedding-3-small`.
3. **Run the full pipeline**
   ```bash
   bash run_video_pipeline.sh
   ```
   - Uses `first_100_videos.txt` by default.
   - You can also pass specific video names:
     ```bash
     bash run_video_pipeline.sh Efk3K4epEzg 4A8orzGYQRI
     ```
   - Processes up to 4 videos in parallel by default. Pipeline stages for each video run sequentially within that video's worker.
   - Set `MAX_PARALLEL_JOBS` to control concurrency. Use 1 for a fully sequential run:
     ```bash
     MAX_PARALLEL_JOBS=1 bash run_video_pipeline.sh
     MAX_PARALLEL_JOBS=2 bash run_video_pipeline.sh Efk3K4epEzg 4A8orzGYQRI
     ```
   - Detailed memorization output is stored in `data/logs/<video>_memo.log`. Set `HVM_VERBOSE=1` to mirror it to the terminal.

## What `run_video_pipeline.sh` does

1. Download shared subtitle data via `preprocessing/download_hf_folder.py`
2. Download each video via `preprocessing/download_hf_videos.py`
3. Add subtitles and extract frames via `preprocessing/add_subtitles_and_extract_frames.py`
4. Build graph memory via `process_full_video.py`
5. Run QA reasoning via `reason.py`
6. Run the `30_10`, `50_30`, and `100_60` threshold-abstraction experiments and their QA reasoning
7. Clean up temporary threshold graphs, downloaded MP4s, and extracted frames

## Outputs

Per successfully processed video:

- `data/graphs/<video>.pkl` (final graph memory)
- `data/graphs/<video>_preabstraction.pkl` (reusable pre-abstraction checkpoint)
- `data/memorization/<video>.json` (episodic memory and memory token summary)
- `data/reasoning/<video>.json` (default QA reasoning results)
- `data/ablation/reasoning_abs/<threshold>/<video>.json` (threshold-abstraction reasoning results)
- `data/logs/*.log` (memorization, reasoning, and ablation logs)

## Data Structure

Expected layout in `data/` (some folders are created or populated during pipeline runtime):

```text
data/
├── frames/
│   └── <video>/
│       └── <clip_id>/
│           └── *.jpg
├── videos/
│   └── <video>.mp4
├── subtitles/
│   └── robot/
│       └── <video>.srt
├── graphs/
│   ├── <video>.pkl
│   └── <video>_preabstraction.pkl
├── memorization/
│   └── <video>.json
├── reasoning/
│   └── <video>.json
├── ablation/
│   ├── graphs_abs/
│   │   └── <threshold>/<video>.pkl
│   └── reasoning_abs/
│       └── <threshold>/<video>.json
├── logs/
│   └── *.log
├── episodic_memory.json
├── reason_summary.json
├── memorization_tokens.json
└── web_100.json
```

Notes:

- `frames/`, `videos/`, and threshold graph files under `ablation/graphs_abs/` are temporary runtime artifacts cleaned up by `run_video_pipeline.sh`.
- Main graphs, pre-abstraction checkpoints, memorization results, reasoning results, threshold reasoning results, and logs are persistent outputs.
- `episodic_memory.json`, `reason_summary.json`, and `memorization_tokens.json` are generated by `scripts/data/reorganize_outputs.py`.

## Combine Pipeline Outputs

After the pipeline finishes, combine the per-video memorization and default reasoning results:

```bash
python scripts/data/reorganize_outputs.py
```

The script reads `data/memorization/` and `data/reasoning/`. It writes:

- `data/episodic_memory.json`
- `data/reason_summary.json`
- `data/memorization_tokens.json`

## Project Structure

Core pipeline:

- `process_full_video.py` - build graph memory with behavior, conversation, appearance, and OCR information
- `reason.py` - run the default four-tool reasoning agent
- `run_video_pipeline.sh` - end-to-end pipeline runner
- `preprocessing/` - dataset and video download, subtitle rendering, and frame extraction
- `classes/` - graph, node, edge, conversation, OCR, and structured-output models
- `reasoning/` - default reasoning agent, prompts, runtime, trace formatting, and tools
- `utils/` - shared memorization prompts, search helpers, and model adapters
- `configs/` - threshold-abstraction configurations used by the ablation pipeline

Alternative reasoning implementations:

- `reasoning_variants/` - historical prompts and alternative reasoning implementations retained for comparison and reproducibility

Experiment entrypoints:

- `scripts/ablation/abstraction_ablation.py` - rebuild threshold abstraction from a pre-abstraction checkpoint
- `scripts/ablation/noise_injection.py` - construct graphs for the noise-injection experiment
- `scripts/ablation/` - threshold and noise experiment runners

Supporting code:

- `scripts/data/` - combine per-video pipeline outputs
- `scripts/analysis/` - memorization statistics and plotting
- top-level `scripts/*.py` - triple extraction benchmarks, graph inspection, and visualization
- `docs/` - architecture notes and experiment analysis
